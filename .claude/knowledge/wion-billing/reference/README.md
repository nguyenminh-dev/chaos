# Reference Materials

This directory contains reference materials for the Billing Service, including glossaries, diagrams, and supporting documentation.

## Contents

### [Glossary](./glossary.md)
The ubiquitous language used throughout the Billing Service documentation and codebase. This defines the common vocabulary shared by domain experts, developers, and stakeholders.

### Terms
- **Wallet**: Digital wallet belonging to a tenant
- **Wi Credit**: Internal payment unit (1 VNĐ = 1 Wi Credit)
- **Balance**: Available funds for consumption
- **Reserved Balance**: Funds locked for pending transactions
- **Payment**: Financial transaction for wallet topup
- **Invoice**: Electronic invoice document
- **Ledger**: Double-entry accounting record
- **Tenant**: Business entity using WION platform
- **Aggregate**: Consistency boundary in DDD
- **Bounded Context**: Logical boundary around a domain

## Purpose
The glossary ensures consistent communication and understanding of domain concepts across teams and documentation.

## Usage
- Refer to this glossary when reading any Billing Service documentation
- Use these terms consistently in code, documentation, and discussions
- Update this glossary when new domain concepts emerge
